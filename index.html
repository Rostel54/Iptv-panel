  • Une connexion administrateur sécurisée.
  • Une base de données pour conserver les comptes.
  • Une API protégée entre le panel et l’application.
  • Un serveur ou fournisseur autorisé pour les flux vidéo.
  • Des sauvegardes et des règles de sécurité.
